# 视频号数据导出

一个 Chrome / Edge 浏览器扩展：把视频号助手里**所有视频的标题和播放数据**一键导出成 Excel。Windows 和 Mac 都能用。

## 导出的内容

- **汇总**：总播放量、按年份和可见范围的统计、播放量前 20 名
- **全部视频**：标题、发布时间、可见范围、时长、播放量、昨日播放、爱心、拇指赞、评论、转发、新增关注、取消关注、完播率、平均播放时长、快速划走率、完整文案

## 安装

1. 下载 [ChannelsExport.zip](https://github.com/suyin101/ChannelsExport/releases/latest/download/ChannelsExport.zip) 并解压，把解压出的文件夹放在一个不会被删除的位置。
2. 在浏览器地址栏打开扩展页面：Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
3. 打开“开发者模式”开关。
4. 点“加载已解压的扩展程序”，选择解压出的文件夹（里面能直接看到 `manifest.json`）。

## 使用

1. 点浏览器工具栏上的扩展图标，会打开视频号助手。没看到图标的话，先点拼图按钮把它固定出来。
2. 用微信扫码登录。
3. 点页面右下角的“开始导出”，翻页期间停留在这个标签页。
4. 完成后 Excel 会自动保存到浏览器的下载文件夹。

每页 20 条，每翻一页会停 3～5 秒，1000 条视频大约需要 5 分钟。

## 隐私

- 只在 `channels.weixin.qq.com` 上运行，没有服务器，数据不会上传到任何地方。
- 不读取微信密码，不发起额外请求，不修改、发布或删除任何内容。它只是记录网页本来就会收到的列表数据，并自动点“下一页”。

## 注意

- 这不是微信官方工具。视频号后台改版后，可能需要更新扩展。
- 不要频繁导出，以免操作过于频繁被平台限制。
- 只能导出你登录的账号有权查看的视频。

## 开发

运行 `./release.sh`，会在 `dist/` 里生成安装包。Excel 生成用的是 [ExcelJS](https://github.com/exceljs/exceljs)（MIT 协议），已包含在 `extension/lib/`。
